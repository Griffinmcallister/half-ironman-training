# Half Ironman 70.3 Training Plan PWA

Files in this folder:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png
- apple-touch-icon.png

For GitHub Pages:
1. Create a new public GitHub repository.
2. Upload ALL files from this folder to the repository root.
3. Open Settings -> Pages.
4. Under Build and deployment, select "Deploy from a branch".
5. Select branch "main" and folder "/ (root)", then Save.
6. Open the generated https://<username>.github.io/<repository>/ URL on iPhone Safari.
7. Share -> Add to Home Screen -> Open as Web App -> Add.

When updating:
Replace the files in the same repository. The installed web app will retrieve updated files when next opened online.
